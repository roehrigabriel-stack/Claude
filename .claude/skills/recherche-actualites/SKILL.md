# Veille d'actualités contextualisée

## Étapes

1. Lis `context/CONTEXT.md` : objectifs, projets, centres d'intérêt, école (FASNY, New York).
2. Construis 3 à 5 requêtes de recherche à partir de ce contexte. Toujours inclure :
   - une requête sur l'actualité générale (France et États-Unis)
   - une requête sur New York si utile (météo, transports, événements)
   - une requête par centre d'intérêt listé
3. Lance les recherches web (mode "standard") dans le même tour.
4. Garde uniquement les actualités des dernières 24 à 48 heures, en lien réel avec Gabriel. Écarte le bruit.

## Format de sortie

- 3 à 5 puces maximum, en français
- Une phrase par actualité, puis la source entre parenthèses avec le lien
- Si une actu touche directement un objectif de Gabriel, dis lequel en quelques mots
- Pas de tirets longs
